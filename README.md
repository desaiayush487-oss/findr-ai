# Findr.AI — Campus Lost & Found Intelligence Platform

Findr.AI is a modern, full-stack web application designed to help university students quickly locate and recover lost items on campus using automated keyword match analysis and image verification.

## 🚀 Key Features
- **User Authentication:** Secure JWT-based registration and login system.
- **Interactive Dashboard:** Live campus report feed with real-time keyword search and category filtering.
- **Local Image Attachment:** Instant image preview and direct file upload support from local device storage.
- **My Reports & Status Lifecycle:** Dedicated user view to track posted items and toggle report status (Open vs. Resolved).
- **AI-Powered Match Engine:** Smart candidate ranking algorithm matching lost & found reports by category, title keywords, and campus location.
- **Automated Claim Notifications:** Direct recruiter/claimer contact action flows.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Lucide React, React Router Dom
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose ORM
- **Authentication:** JSON Web Tokens (JWT), bcryptjs
